# MTG Life Scouter — Android V0.5

MTG Life Scouter is a local-first tabletop companion for Magic: The Gathering Commander games.

## V0.5 features

- 2, 3, 4, 5, or 6-player life tracking
- Opposite-side panels rotate 180° for across-table readability
- Four-player layout fits on screen without scrolling
- Table controls centered precisely between player sides
- GitHub update control located inside Settings
- Center-bar circular-arrow game reset control
- Full-spectrum color picker for every player tile
- Per-player commander damage summaries identify each attacker
- Hold life controls to change life by 10
- In-app GitHub release update checker and APK downloader
- Commander damage per opponent
- Poison/toxic and energy counters
- Editable player names
- Device-local player-card images
- Device-local table background image
- Adjustable image overlay for readability
- Persistent game and appearance settings
